# PGSharp Pessoal

Projeto experimental de personalização local para organização de favoritos no Android.

## Objetivos
- Mover e reordenar favoritos arrastando;
- Editar nomes, emojis e categorias;
- Pesquisar filtros;
- Preservar histórico e backup.

## Estado
- Este repositório contém apenas a documentação inicial.
- O módulo experimental de edição permanece em pacote local, **não publicado aqui**.
- **Ainda não há um APK recompilado e validado em Android.**
- A edição direta da lista de favoritos ativa não foi comprovada.

## Privacidade
Este repositório está **público**. Para uso particular, vá em **Settings > General > Danger Zone > Change repository visibility > Make private** antes de enviar o código do módulo.

Não inclua APKs de terceiros, `PGSData.dat`, `PGSStats.json`, senhas, tokens, keystores ou backups da conta no GitHub.

## Implementação
Integração Android experimental, sem remoção de licenças ou mecanismos de segurança. Exigir testes de funcionamento, assinatura, importação/exportação e segurança antes de instalar.
